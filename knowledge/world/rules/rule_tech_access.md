# 设备、机构和伙伴不是个人技能

标识：`rule_tech_access`｜类别：rules

## 归纳

异常技术依赖载体、能源、操作者、知识、位置和维护。认识制造者或经历一次操作，并不等于掌握或持有装置。

## 认识层级

synthesis

## 边界

- 毁坏、停机、被收回和离开地球的资源不能凭历史存在直接调用。
- 勒曼医院和康维可以拒绝、误判、失败。

## 演绎应用

调用能力时核对设备现在在谁手中、是否运作、角色是否会用、能否得到帮助。
