# 统一世界、时间线与 RP 使用说明

这套世界可以按“日常社会仍在运作，而异常生命、技术和知识分布极不均匀”来组织。警察需要证据，医生会遇到知识边界，企业和秘密组织争夺资源，家庭与爱情影响人的选择。异常常从一个人、一件器物、一处遗迹或一次失踪进入生活，再把调查引向更大的生命和文明问题。

本次按用户要求，把九个系列的 **336 个清理后文本**放进共同背景。直接串场保留原作连接；其余共存属于项目整合前提。这 336 个单位包括背景介绍和分开的续段，不能简单等同于 336 部独立长篇。总入口见 [world/README](../knowledge/world/README.md)，机器入口见 [index.json](../knowledge/world/index.json)。

## 这个世界怎样运作

### 日常秩序与异常知识的分布

高斯、李玉芳与木兰花一方提供城市和社会制度的基底：摄影、证词、侦查、交通、企业、警务协作依然有效。异星文明存在，也不妨碍某件怪事是普通骗局。原振侠的医院、卫斯理的家庭、罗开的交游和高达的行动团队，则是不同的异常事件入口。它们因朋友、病人、委托、旧案或技术需要连接，尚无证据把它们合并为一个共同组织。参见 [隐秘世界规则](../knowledge/world/rules/rule_hidden_world.md)、[高斯的职业边界事件](../knowledge/world/events/s_police_boundary.md)。

知识具有实际来源。有人亲历装置，有人只听过鬼神故事，有人得到被删节的解释。齐白和李宣宣在阴间生活过，也不懂一至四号的全部来历；康维因身体无水免受某类干预，同时也收不到同一渠道的消息。**世界事实、角色相信的事、主持人知道的事要分开保存。**参见 [知识规则](../knowledge/world/rules/rule_knowledge.md)。

### 权力从哪些地方产生

| 节点 | 能影响什么 | 限制和内部张力 |
| --- | --- | --- |
| [勒曼医院](../knowledge/world/entities/leman.md)及[非常物品交易会](../knowledge/world/entities/extraordinary_exchange.md) | 以医疗、复制与稀缺技术连接政要豪富，影响交易和隐秘行动 | 研究者未必共享全部技术；客户依赖、复制人的自主与机构目标可能冲突 |
| [非人协会](../knowledge/world/entities/nonhuman_association.md) | 招揽有独特经历者，组织调查和生命研究 | “非人”是资格称谓；会规、成员和研究目标随阶段变化，不共享全部本领 |
| [阴间与思想仪](../knowledge/world/entities/underworld.md) | 灵魂收容、通讯、部件追索与思想控制的可能 | 仪器有残缺和盲区，管理员也有分歧；终局已停摆 |
| [爱神星及培育计划](../knowledge/world/entities/aishen_world.md) | 救援、生命实验、神经技术与新的生活环境 | 科技仍受灾难、认知及伦理问题约束 |
| [幽灵星座](../knowledge/world/entities/ghost_constellation.md) | 灵魂采集、研究、任务和惩罚 | 使者能背离任务；与阴间没有被证实为同一个体系 |
| [水生命](../knowledge/world/entities/water.md)与[山腹长老](../knowledge/world/entities/elder.md) | 让人类面对生态尺度、古代工程与生存选择 | 各自有意志和立场，接触与解释有条件；强大不代表其方案必然正确 |

人类权力也持续有效：金钱能支持远征、交易或胁迫，国家与组织能招募和操纵，但都可能在自己不理解的异常前失效。项目没有增设一个支配这些势力的“最终幕后”。

### 生命、死亡和能力

本世界允许人类、机械生命、异星生命、离体意识等不同存在，但不同个案的身体、思想、知识与灵魂不能互换。高达副本能反抗外加指令，杜良副本却不能学习新知识；奥丽卡的灵魂进入黑纱留下的身体，并非两个灵魂合体；神鹰成人后仍通鹰语，却失去自身飞行。参见 [生命形态](../knowledge/world/rules/rule_plural_life.md)、[复制技术](../knowledge/world/entities/leman_copy.md)、[神鹰成长线](../knowledge/world/arcs/arc_shenying.md)。

因此，保存灵魂、复制身体、恢复功能、移植器官、延续寿命是不同任务。某项有成功个案，另一项仍可能失败。陈长青失去肉身后仍然痛苦；天使的牺牲不会因宇宙有灵魂技术而自动撤销；原振侠终局失踪，去向和存亡未证。参见 [死亡规则](../knowledge/world/rules/rule_death.md)。

能力应经过“来源—载体—操作者—对象—条件—代价—当前状态”的检查。仪器、医院、朋友、师门与一次奇遇都要实际在场或能被联系。降头和巫术保留媒介、禁制、对象关联及反噬；武术人物保留受伤、失明、疲劳与恢复过程。成长既可能获得新能力，也可能失去旧身体的优势。

### 多套解释如何兼容

长老关于七种外星生命与地球改造的自述，提供了一条远古工程史；阴间、神话投影、幽灵星座和鬼话则提供不同层次的异常经验。目前证据不足以把它们压成唯一创世模型。共同世界允许这些解释各有适用范围，并允许人物意见冲突。鬼话里的无影、重复归来和留号，可以保留未知；无需替每个短篇指定一种已知机器。参见 [起源解释规则](../knowledge/world/rules/rule_world_origin.md)、[局部机制规则](../knowledge/world/rules/rule_local_mechanisms.md)。

## 世界发生过什么：使用事件偏序

没有足够证据给全部作品排列公历年表。当前 [timeline.json](../knowledge/world/timeline.json) 收录 **67 个关键事件节点、38 条关系**；只有 `before` 表示先后，`revealed_by` 只表示“后来在哪次调查中获知”。部分节点概括一段连续过程，`multi_event_group` 则明确表示多个联系事件，不能当作同一天。

| 事件链 | 世界／人物状态的变化 | 时间约束的意义 |
| --- | --- | --- |
| 少年神秘联络 → 《将来》的身份揭露 | 卫斯理由不明声音的来历，发展到知道航行小组和残缺思想仪 | 揭露晚于亲历；童年没有成年人的解释 |
| 《后备》 → 《蜂后》 | 医院秘密曝光，迁址；高达原本与复制体分流 | 《蜂后》直接回指，是跨系列锚 |
| 《犀照》 → 《黑白无常》 | 胡怀玉及研究所继续参与新调查 | 只能约束这两个相关事件，不能排序两系列所有书 |
| 《幽灵星座》 → 《黑暗天使》 → 《夜归》 | 黑纱受罚、牺牲，奥丽卡使用新身体 | 新身体及其实际展示能力在换身后生效 |
| 血魇施术 → 解咒反噬 → 《假太阳》恢复 → 失踪后的搜寻 | 玛仙先失能，再经救治改变；仍无法保证找到原振侠 | 不能把终局能力提前使用 |
| 《开心》鹰身 → 《真实幻境》 → 成人 → 再赴孤峰 | 神鹰改变身体与行动方式，红绫尊重其离去 | 幻境形态与稳定身体分开 |
| 安妮加入家庭 → 轮椅阶段办案 → 《猎头禁地》后行走 → 后期学习 | 身体、知识和责任分阶段改变 | 康复原因未定，不能转为通用疗法 |
| 长老接触 → 温宝裕的激进主张 → 新生大同盟 | 拯救世界的愿望从强制改变别人转向邀请自愿远行 | 终局邀请未证明任何人已经出发 |
| 阴间仍运作 → 终局停摆与齐白断讯 | 旧有设备、通讯和收容条件不再可用 | 灵魂与管理员去向继续未知 |

这些链之间常常不可比较。**没有先后路径，表示先后未知，不表示同时。**“全部角色最后明确状态”是参考矩阵；要让它们在同一天共处，属于明确选择的综合终局沙盒。

书目排序尤其容易误导：《少年卫斯理》是回忆；《粉红钻石》开头回述《奇迹》后事，编号 04 与 17 并非事件时间；高达八个文件没有一致顺序。非人协会三月一日聚会属于年度月日，《天人》文末的 1981 年新闻日期属于嵌入材料，都不用于给整个世界定年。参见 [目录与年代问题](../knowledge/world/issues/issue_catalog_order.md)。

全部 336 个文本另有 [逐书证据入口](../knowledge/world/README.md#全部文本的事件证据入口)，能定位其他案件的人物行动、变化、结局和未决点。它们复用既有证据注释，不冒充新写的完整情节梗概。

## 角色怎样经历和成长

[24 条成长线](../knowledge/world/README.md#角色经历与成长)把事件转成演绎约束，另外为全部 1,409 个既有角色建立逐书经历入口。核心不是升级表，而是角色下一次面对类似问题时，为什么会有不同反应。

- 卫斯理的知识扩大，好胜、偏爱与求知越界也持续存在；白素由白家女儿、伴侣、母亲走到非人协会成员，保护他人与尊重自主之间仍有张力。
- 红绫学会知识，也会保护旧有动物关系、保留秘密和支持伙伴离去；神鹰获得人身时实际失去飞行。
- 原振侠从救人者变成求援者，需要面对爱人选择与自己的无能为力；玛仙愿为错误施术承担反噬，恢复后的生活尺度又改变亲密关系。
- 罗开拒绝受控，却也会被欲望动摇；高达真诚经历丧失，仍保留浪子和越轨的一面。他的副本另有自己的爱情。
- 年轻人与公主从相互算计走向共同生活，新身体改变两人的认知差异；年轻人需要承认公主可能比自己更明白处境。
- 木兰花经历失明与受助，安妮从需要照护走向能够负责；穆秀珍的婚姻不抹去对马超文的纪念，假新娘的行动也不算她本人。
- 高斯与李玉芳维持亲近和职业边界。经历奇案没有赋予两人豁免普通法律的权利。

历史场景先选阶段，再加载原角色卡的适用性格与技能。既有卡片中的终局记忆、身体或“恢复参战”安排可能晚于场景，不能直接使用。参见 [部署与历史的区别](../knowledge/world/issues/issue_adapted_resurrection.md)。

## 有哪些麦高芬型目标

这里把“麦高芬”用作 RP 的争夺／追索焦点，覆盖物品、人物、信息、地点和概念；不宣称每项都是严格意义的纯麦高芬。每项记录机制的证据层级、接触条件、局限和最后状态，RP 用法另标为改编建议。

| 目标 | 各方追求什么 | 必须保留的状态 |
| --- | --- | --- |
| [生命配额](../knowledge/world/entities/life_quota.md) | 继续活下去、救伴侣、保存贡献或垄断分配 | 特殊个案存在；普通人间普遍转移尚未成功 |
| [思想仪关键部件](../knowledge/world/entities/thought_core.md) | 通行、团聚、控制或阻止思想侵犯 | “借灵魂”包含误听；拿到部件不能复原已坏的整机 |
| [微晶、博士和显示器](../knowledge/world/entities/microcrystal.md) | 知识、财富、脱困、与家人重聚 | 物、人、读取工具分处不同方，缺一不能自动兑现价值 |
| [不死药](../knowledge/world/entities/immortality_drug.md) | 不死及商业利益 | 依赖和人格损害不可删除；药源终局不可随意恢复 |
| [死光表及图样](../knowledge/world/entities/deathwatch.md) | 武器、交易利益、灭口或阻止扩散 | 本案原物和图样已毁，拿到旧箱子也未必有价值 |
| [天书及戒指](../knowledge/world/entities/heaven_book.md) | 预知、求援和归乡 | 解释、能量耗尽、设备毁坏与知情差异均重要 |
| [复制身体与知识转移](../knowledge/world/entities/leman_copy.md) | 医疗后备、知识保存、替身或控制 | 人格自主、输入缺陷、受体意愿及原本／副本身份分开 |
| [水](../knowledge/world/entities/water.md)、[长老](../knowledge/world/entities/elder.md) | 获得帮助、古史知识、解困或拯救世界 | 有意志的当事人可以拒绝，也可能提出不可接受的代价 |
| [天使的任务目标](../knowledge/world/entities/angel_prize.md) | 夺回或毁去重要之物 | 目标已毁，天使已牺牲；不补全未展示功用 |
| [雨夜号码](../knowledge/world/entities/rain_number.md) | 再次联系和解释异常 | 痕迹存在，身份与联络效果未知 |

“得到了目标”应改变局势，而非结束所有问题。副本能拒绝；博士能离去；研究尚无成果也会引起争夺；旧装置损毁后仍留下责任、信息和关系。这些后果让世界持续运转。

## LLM 检索与场景装配

```powershell
# 按词查候选，再用唯一 ID 读取。
python -X utf8 tools/query_world.py 思想仪 --kind entities
python -X utf8 tools/query_world.py underworld --markdown

# 全部书均有定位注释；同名人物返回候选而不默取首项。
python -X utf8 tools/query_world.py --book 微晶之密
python -X utf8 tools/query_world.py --character 红绫

# 只载入在该事件及其已证前置事件中可用的历史。
python -X utf8 tools/query_world.py --scene w_eagle_human --character 神鹰

# 场景另明确完成了哪些支线，可逐项加入。
python -X utf8 tools/query_world.py --scene w_eagle_human --after w_quota_research

# 显式接受本项目的推断先后；默认只走原作接续关系。
python -X utf8 tools/query_world.py --scene w_alliance --include-inferred
```

`--scene` 返回主持人的部分状态包。`frontier_event_ids` 对应当前尚未被后续事件覆盖的状态约束，`confirmed_history_stages` 仅供回溯，不叠加旧能力。如果同一人物有几个不可比较的状态，会全部保留并标识，不自动选择最后一条。

场景包不载入终局人物卡或终局物件状态，也不自动填充角色的 `knows`。默认前置集合只由已标注的 `before` 关系展开；未纳入的支线可能发生过，也可能没有，需主持人结合场景补足。一个事件节点还可能含多个阶段，精确到其中某一天时应回读引文并拆分。

可供系统提示使用的约定：

> 采用项目统一世界前提。先读取场景的已完成事件、参与角色、身体状态、实际资源与逐角色知情表。将原作事实、证言、假说、项目归纳和场景改编分开。只让角色使用亲历、学会或被告知的信息。以动机和经历决定行动，不复述剧情目录。不默认旧设备仍能运行、朋友必定协助、失踪者已经回来、复制体与原本同一、所有时间线同时抵达终局。证据不足时保持未知，并让调查、协商、选择及代价推动场景。

## 覆盖、维护与验证

本轮全量连接已有 336 文本、1,409 角色及 5,578 条去重后的定位注释；另行整理的规则、实体和关键事件直接关联 85 个文本。本轮直接回读的引用来自 8 个文本，其余引用保留“继承角色注释”来源。**这不是“336 本重新全文精读完成”或“所有世界设定穷尽”的声明。**实际数量随构建更新，读取 [coverage.json](../knowledge/world/coverage.json) 和 [manifest.json](../knowledge/world/manifest.json) 为准。

维护输入位于 `data/worldbuilding/`，成品位于 `knowledge/world/`。不要修改生成的 JSON 或 Markdown。维护已有角色数据仍走原角色库工作流；角色证据变动后，世界构建会要求继承注释重新核对。正文保持在外部 `NK_Source`，不复制进仓库。

```powershell
python -X utf8 tools/build_world_kb.py
python -X utf8 tools/build_world_kb.py --check
python -X utf8 -m unittest discover -s tests -p test_world_kb.py -v
```

构建检查全部正文 SHA-256、原文行界、角色与事件引用、继承注释一致性、唯一 ID 和时间关系无环；`--check` 还逐文件比对成品内容。结构通过不能证明文学解释正确。新增跨书结论应检查证据是否只是提及、回忆、预示或人物自己的看法，再决定是否加入硬性的先后关系。
